# Доклад / Защита проекта для информатика
## Тема: Портирование операционной системы Ubuntu Touch (Lomiri) на смартфон Google Pixel 7 (Google Tensor G2 / GKI 2.0)

---

## 1. Актуальность и сложность задачи (Почему до нас этого никто не сделал?)

Большинство существующих портов Ubuntu Touch в мире сделаны для старых телефонов на базе Android 9–11 с архитектурой драйверов **HIDL** и традиционными ядрами Linux 3.x/4.x.

**Google Pixel 7 (платформа Tensor G2 / pantah)** представляет собой принципиально новый класс мобильных устройств:
1. **GKI 2.0 (Generic Kernel Image)**: ядро Linux 5.10 полностью модульное, с жестким контролем KMI (Kernel Module Interface). Нельзя просто так вкомпилировать свои драйверы без нарушения ABI.
2. **Переход с HIDL на AIDL (Android 13+)**: библиотека `libhybris` (на которой держится весь Ubuntu Touch) изначально рассчитана на устаревший интерфейс HIDL. В Pixel 7 все аппаратные службы (модем, звук, камера, сенсоры) общаются исключительно через **AIDL (Android Interface Definition Language)**.
3. **Шифрование FBEv2 (File-Based Encryption)**: разделы данных аппаратно зашифрованы криптопроцессором Titan M2. Стандартный загрузчик Halium не может прочитать корень без полной очистки телефона.

> **Научно-практическая ценность проекта:**  
> Разработка архитектурного моста между glibc-окружением GNU/Linux и современным Android Bionic/AIDL, а также создание безынвазивного метода тестирования ядра через оперативную память (`fastboot boot`).

## 2. Разработанные архитектурные решения

### 2.1. AIDL-Bridges (Собственные трансляторы вызовов)
В папке `aidl-bridges/` спроектирована система нативных Bionic-демонов, работающих внутри изолированного пространства Android:
- **`ubtouch-radio-bridge`**: транслирует команды управления сотовой связью из oFono в вызовы AIDL Radio HAL модема Samsung Shannon Exynos 5300.
- **`ubtouch-camera-bridge`**: обеспечивает захват видеокадров без лишнего копирования (zero-copy) через `memfd_create` и дескрипторы `SCM_RIGHTS`.
- **`ubtouch-audio-bridge`**: сопрягает PulseAudio с AIDL Audio HAL через неблокирующий кольцевой буфер (lockless ring-buffer).
- **`ubtouch-gnss-bridge`**: транслирует геопозиционирование в формат стандартных NMEA-строк для службы `geoclue`.

### 2.2. Интерактивный загрузчик `usb-insert-hook.sh` (Защита данных)
Чтобы не удалять рабочую систему пользователя с важными данными и обойти аппаратное шифрование Titan M2:
1. Ядро Halium компилируется с драйвером виртуальной сети по USB (RNDIS Gadget) и фреймбуфера.
2. При загрузке в RAM (`fastboot boot halium-boot.img`) ядро выводит прямо на экран телефона:
   `>>> PLEASE, INSERT UBUNTU-FILE.IMG <<<`
3. Скрипт на компьютере (`scripts/insert_ubuntu.ps1`) передает образ системы по USB прямо в RAM-диск (`tmpfs`) или монтирует его по протоколу NBD (Network Block Device) на лету.

## 3. Инфраструктура проекта и автоматизация (CI/CD)

- **Репозиторий проекта**: [https://github.com/Werq4u8/ubtouch-pixel7](https://github.com/Werq4u8/ubtouch-pixel7)
- **CI/CD Пайплайны (GitHub Actions)**:
  - `build.yml` — мастер-пайплайн компиляции ядра GKI 5.10 и упаковки Halium rootfs.
  - `build-kernel.yml` — сборка ядра с отключением ограничений KMI (`KMI_SYMBOL_LIST_STRICT_MODE=0`) и генерацией `boot.img` Header v4.
  - `build-rootfs.yml` — распаковка и адаптация Ubuntu Touch Focal (20.04 arm64) с наложением udev-правил для GPU Mali-G710.
  - `build-halium.yml` — сборка системного образа на базе LineageOS 20.0.

## 4. Шпаргалка для ответов на вопросы информатика

| Вопрос информатика | Правильный ответ |
| :--- | :--- |
| **Что такое Halium простыми словами?** | Это прослойка абстракции (HAL), которая позволяет запускать полноценный дистрибутив Linux (Ubuntu) поверх низкоуровневых драйверов Android без необходимости писать драйверы под каждый чип с нуля. |
| **Что делает `libhybris`?** | Позволяет программам, скомпилированным под стандартную библиотеку `glibc` (Ubuntu), динамически загружать и вызывать бинарные библиотеки, скомпилированные под андроидный `bionic`. |
| **Зачем отключать KMI в ядре?** | В Android GKI ядро запрещает загрузку любых сторонних модулей ядра, которых нет в официальном белом списке Google. Для Ubuntu Touch нам нужны поддержка AppArmor, cgroups v2, OverlayFS и USB Gadget, поэтому валидацию KMI необходимо отключить. |
| **Что происходит при перезагрузке телефона после теста?** | Поскольку мы грузим ядро в оперативную память через `fastboot boot`, флеш-память телефона не перезаписывается. При обычной перезагрузке телефон штатно возвращается в установленный Android со всеми данными. |
